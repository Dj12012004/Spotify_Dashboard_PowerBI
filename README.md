# Spotify Music Analysis Dashboard 

![Image](https://github.com/user-attachments/assets/438b61c0-cabf-42f6-8f3e-9ab0ade1f29c)

This project presents an in-depth analysis of the most-streamed songs on Spotify as of 2023. Using Microsoft Power BI, an interactive dashboard was developed to uncover trends, patterns, and listener behavior across 950+ tracks and 489 billion streams. The dashboard highlights what makes a song a global hit and provides actionable insights for artists, producers, and stakeholders in the music industry.

# Project Overview

The dashboard provides a centralized view of Spotify streaming data, focusing on trend reporting and artist insights. It enables dynamic filtering by track, artist, and time period, allowing users to explore:

* Total Streams and Track Counts
* Artist Performance
* Seasonal & Weekly Trends (by month and day)
* Top Tracks & Billion-Stream Hits

# Workflow and Methodology

**1. Data Collection** - Gathered streaming metadata of Spotify’s most-streamed tracks.

**2. Data Cleaning & Preprocessing (Power Query)** - Removed duplicates and handled missing values. Standardized data types (numerical and date fields). Extracted Year, Month, and Day Name for time-based insights.

**3. Data Transformation** - Processed streaming activity across 12 months and 7 days, enabling seasonal and weekly behavior analysis.

**4. Data Analysis (DAX Measures)** - Created key measures including Total Streams, Total Tracks, Average Streams. Developed weekly/monthly usage metrics aligned with listener adoption trends.

**5. Data Visualization (Power BI)** - Built an interactive dashboard with slicers for Date and Artist(s). Used cards, line charts, bar charts, and tables to present insights clearly.


# Key Findings & Insights

* Massive Streaming Volume: 950+ tracks generated 489B total streams, averaging 514M per song.

* Modern Music Boom: Streams surged after 2000, peaking in the late 2010s and early 2020s.

* Fridays Dominate: Identified Fridays as peak listening days, aligning with global release schedules.

* Seasonal Trend: January emerged as the highest streaming month, offering insights for release strategy planning.

* Top of the Charts: Blinding Lights by The Weeknd remains the most-streamed track with 3.7B+ streams.

* Actionable Insights: Delivered recommendations to align release planning with weekly/monthly adoption patterns.

# Conclusion
This project demonstrates how business intelligence tools like Power BI can transform raw streaming data into meaningful insights. The Spotify Music Analysis dashboard provides a clear view of streaming behavior, supporting both artist performance evaluation and strategic release planning.
